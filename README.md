# 课堂哨 · 直播二维码提醒

课堂哨是适用于 **Google Chrome 和 Microsoft Edge** 的浏览器插件。开启后，它监控课程视频中的二维码，通过循环声音、系统通知和网页指示灯提醒你返回课堂；也可以将识别到的网页链接自动打开到后台标签页。

优先适配上海交通大学课程直播、点播页面；其他普通网页可手动框选需要监控的画面。**每个浏览器同时监控一个标签页。**

## 安装

插件安装包：[课堂哨-Edge-Chrome-0.1.1.zip](https://github.com/OrangeCaaat/sjtu-webcast-QRcode-detector/releases/download/v0.1.1/%E8%AF%BE%E5%A0%82%E5%93%A8-Edge-Chrome-0.1.1.zip)。独立说明：[课堂哨-使用指南.md](https://github.com/OrangeCaaat/sjtu-webcast-QRcode-detector/releases/download/v0.1.1/%E8%AF%BE%E5%A0%82%E5%93%A8-%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97.md)。

1. 将安装包解压到一个固定文件夹，确认该文件夹内直接包含 `manifest.json`。
2. 在浏览器中打开“管理扩展”标签页；或在 Chrome 地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的文件夹，**不能直接选择 ZIP，也不要选择它的上一级目录**。
5. 从浏览器扩展菜单找到“课堂哨 · 直播二维码提醒”，将图标固定到工具栏。

安装后保留解压目录，不要移动或删除。Chrome 和 Edge 需要分别安装。

## 开始监控

1. 打开并播放课程直播或点播，保持课程是浏览器当前选中的标签页。
2. **交大课程的直播主窗口应显示 PPT 界面**，不要把教师摄像头画面放在主窗口。
3. 点击课堂哨图标，先“测试声音”，确认能听见后点击“停止测试”。
4. 点击“开始监控”，查看面板中的“监控画面”，确认覆盖正确的课程大画面。
5. 若选错，点击“换选播放器”；仍不正确时使用“手动框选区域”，拖拽覆盖整个课程画面，尽量避开网页侧栏。
6. 确认网页控件显示“监控中”，即可关闭插件面板并切换到其他软件。

**浏览器可以被其他软件遮挡或最小化，但课程标签页应保持选中，电脑应保持唤醒。** 关闭插件面板不会停止监控。

网页控件挡住按钮时，拖动左侧拖动柄即可移动；点击“收起”只保留一个指示灯，点击指示灯展开。指示灯也可拖动，收起不会停止监控或报警。

## 报警后处理

二维码出现后，声音持续循环，页面和系统通知同时提醒。返回课程确认内容，点击任一入口的 **“停止报警”**：

- 网页浮动控件，收起状态下先点击指示灯展开。
- 插件控制面板。
- 系统通知中的按钮。

**停止报警只停止声音，检测继续。** 关闭系统通知不会消警；结束本次监控应点击“停止监控”。

同一轮二维码持续显示或原地刷新时，不会重复响铃。所有二维码消失并完成冷却后进入下一轮，下一次出现二维码时重新报警。疑似二维码无法解码时会注明“疑似二维码，未解码”，请返回课程确认。


| 显示状态     | 含义及操作                                     |
| -------------- | ------------------------------------------------ |
| 监控中       | 正在检测选定画面                               |
| 检测到二维码 | 本轮已确认二维码或疑似结构；处理后可停止报警   |
| 冷却中       | 二维码已消失，等待冷却完成；检测仍继续         |
| 正在恢复     | 正在尝试恢复采集或确认监控区域                 |
| 出现问题     | 无法正常监控；查看原因，重新框选或“重试监控” |
| 已停止       | 本次监控已结束；需要时重新开启                 |

监控故障使用另一种提示音。故障恢复后，已经触发的声音仍需手动停止。暂停课程视频时继续检测当前画面，不因暂停而故障报警。

## 常用设置

保存后立即生效，无需停止并重新开启监控。


| 设置         | 可选范围与默认值                          | 说明                                                       |
| -------------- | ------------------------------------------- | ------------------------------------------------------------ |
| 检测间隔     | **0.25s / 0.5s / 1s / 2s**；默认 **0.5s** | 两次检测之间的时间；间隔越短，检测越频繁，资源占用通常越高 |
| 冷却时间     | **1–300 秒整数**；默认 **10 秒**         | **二维码消失多久后，恢复监控状态**；无效输入保留原值       |
| 报警音量     | **0–100%**；默认 **70%**                 | 0% 静音；实际声音还受系统和浏览器音量影响                  |
| 自动打开链接 | 默认**关闭**                              | 开启后，识别到的网页链接在后台标签页打开，保持课程页选中   |

### 报警声音

点击齿轮或“导入音乐”进入声音设置。支持 **MP3 / WAV / OGG，单个文件不超过 20 MB**。导入失败会说明原因并保留原有声音，也可以恢复默认提示音。

二维码报警使用默认提示音或导入音乐；故障始终使用另一种提示音。设置页可分别“测试二维码报警”“测试故障报警”，测试声音持续播放，需点击“停止测试”。

### 自动打开链接

只打开 **HTTP / HTTPS** 链接，保留链接参数。每处二维码每轮首次解码时打开一次，同一完整链接在该轮只开一页，同处动态刷新不会不断开页。二维码位置无法确认时暂停自动开页，可使用面板中的手动入口。

普通文本和其他协议内容可查看、复制。打开链接后，仍需按课程要求完成签到或答题。

## 常见问题


| 问题                               | 检查与处理                                                                                              |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| 没有检测到二维码                   | 检查预览是否包含二维码、交大主窗口是否为 PPT 画面；尝试重新框选。过小、严重模糊或被遮挡的码可能无法识别 |
| 听不到声音                         | 分别测试两种报警，检查插件音量、Windows 音量混合器、输出设备及浏览器静音状态                            |
| 没有系统通知                       | 检查系统通知权限和勿扰模式；仍可通过声音、页面控件及插件面板处理                                        |
| 消警后仍显示“检测到二维码”       | 如果二维码还在画面中，这是正常状态；全部消失并完成冷却后恢复“监控中”                                  |
| 滚动、缩放或改变窗口大小后出现问题 | 手动区域需要重新确认或框选；自动选区也应检查预览是否正确                                                |
| 全屏时找不到网页控件               | 浏览器原生视频全屏可能不显示控件；使用系统通知，或退出全屏后操作                                        |
| 重启后提示上次异常结束             | 浏览器退出、插件禁用及电脑睡眠期间无法报警；恢复后重新开启监控                                          |

## 更新插件

将新版文件解压并覆盖原安装目录，在扩展管理页点击“重新加载”，然后刷新课程页、重新开启监控。使用原安装目录更新可保留该扩展的设置。若安装成另一份扩展，设置可能独立；避免同时开启两份课堂哨。

## 可选：手动测试工具

`课堂哨-手动验收工具.zip` 提供可控的合成课程画面，支持显示、隐藏、同处刷新二维码，以及 10 秒或 30 分钟定时显示。它用于检查报警、冷却、遮挡和最小化，不是插件运行的必需组件。

解压后双击“启动手动验收页.cmd”，保持启动窗口打开；复制窗口显示的本机地址到要测试的浏览器，使用插件手动框选白色课程画面。**测试工具需要 Python，插件本身不需要。** 完成后在启动窗口按 `Ctrl+C` 停止。

详细测试步骤见 [实机验收操作指南.md](实机验收操作指南.md)。开发、构建和发布说明见 [readme-dev.md](readme-dev.md)。
